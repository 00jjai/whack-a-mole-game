About

Whack-A-Mole is a reaction-based game where players click moles before they disappear. The game gets harder as your score increases.

Features

• Animated moles
• Custom hammer design
• Score tracking
• Countdown timer
• Progressive difficulty

Built With

HTML, CSS, JavaScript, ProcessingJS, and GitHub Pages.
